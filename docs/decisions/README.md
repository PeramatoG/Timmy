# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for TIMMY.

ADRs should be added when a significant architectural decision is introduced,
replaced, or deliberately reconsidered.

Examples include:

- replacing the audio backend;
- changing the default ASR strategy;
- introducing a new cross-module abstraction;
- changing the command-processing model;
- making a decision that significantly affects portability, licensing,
  maintainability, or runtime behavior.

The Project Charter remains the primary architectural contract.

ADRs document why an intentional architectural change was made.
